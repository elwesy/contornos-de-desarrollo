HISTORIA 1 SOCIO

Como socio de la biblioteca, quiero consultar la disponibilidad de un libro para saber si puedo solicitarlo en préstamo



Historia 2 BIBLIOTECARIO

Como bibliotecario, quiero registrar el préstamo de un libro a un socio para mantener actualizado el número de ejemplares disponibles



Historia 3 ADMINISTRADOR DEL SISTEMA

Como administrador del sistema, quiero registrar nuevos libros en el catálogo para mantener actualizada la información de los libros disponibles en la biblioteca.

|Independent|Si, la consulta puede desarrollarse sin implementar prestamos|Si, pero utiliza datos de libros y socios existentes|si, el alta de libro no depende del resto|
|Negotiable|Si, se puede acordar que información mostrar|si, se pueden negociar los datos y condiciones|Si, se pueden acordar los campos obligatorios del libro|
|Valuable|Si, permite conocer disponibilidad antes de solicitar un libro|si, facilita el control de prestamos y ejemplares|si, permite mantener actualizado el catalogo|
|Estimable|Si, la consulta esta bien delimitada|Si, el registro del prestamos esta definido|si, se conoce la operación y sus datos basicos|
|Small|Si, solo consulta la disponibilidad|Si, solo registra un prestamo|si, solo registra un libro|
|Testable|si, se puede comprobar la disponibilidad mostrada|si, se comprueba el prestamos y la reducción de ejemplares|si, se verifica que el libro aparece en el catalogo|



Historia elegida (BIBLIOTECARIO)



Criterio 1 — Préstamo realizado correctamente

\- Dado que un socio está registrado y un libro tiene 3 ejemplares disponibles.

\- Cuando el bibliotecario registra el préstamo de un ejemplar a ese socio.

\- Entonces el préstamo queda registrado y el número de ejemplares disponibles disminuye a 2



Criterio 2 — Préstamo sin ejemplares disponibles

\- Dado que un socio está registrado y un libro tiene 0 ejemplares disponibles.

\- Cuando el bibliotecario intenta registrar el préstamo.

\- Entonces el sistema rechaza la operación, no registra el préstamo y mantiene 0 ejemplares disponibles.
